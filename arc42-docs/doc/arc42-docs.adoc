.Abstract
This document describes the architecture of Little Trotter X-Invoice, an invoicing and receipt-management application that produces UStG-compliant, ZUGFeRD capable e-invoices. It follows the https://arc42.org[arc42] template and is built with https://doctoolchain.org[docToolchain]. This documentation supports software development and architecture. All source code and documentation are provided in English.
